# 简介

## 这是一个用 C++ 制作的开源游戏，包含了 *游戏主体*、*地图编辑器*、*服务器* 多种功能。

## 目前仍处于开发阶段，还有很多部分不够完善，可先在 [Releases](https://github.com/alien547/Purge/releases) 下载早期版本游玩。

# 游戏开发规范

## 命名规范：

### 1. 变量、函数：

#### 使用 *蛇形命名法（snake_case）*。

#### 所有字母 *小写* 且单词之间用 *下划线* 连接。

### 2. 类、结构体、文件：

#### 使用 ​*大驼峰命名法（PascalCase）​*。

#### 单词 *首字母大写* 且 *无分隔符*。

### 3. 常量、宏：

#### ​使用 *全大写蛇形命名法（SCREAMING_SNAKE_CASE​）*。

#### 所有字母 *大写* 且单词之间用 *下划线* 连接。

### 4. 其它：

#### 局部用短名（简洁），全局用全名（准确）。

#### 少用宏。

#### Windows 相关变量使用 *匈牙利命名法（Hungarian Notation）*。

#### 头文件用“*.h”，源文件用“*.cpp”。

## 格式规范：

### 1. 缩进使用 4 个空格。

### 2. 单行语句可不使用花括号。

### 3. 花括号使用后换行。
